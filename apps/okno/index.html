        ИИ-помощник

        Понимает фразы с опечатками и разговорной речью: «завтро в 3 стамотолог», «в пн и ср в 10 зал». Работает через ваш ключ API Claude. Ключ хранится только в этом браузере и уходит только в Anthropic. Без ключа работает встроенный разбор с исправлением опечаток.

        Google Calendar

        Новые события будут записываться и в ваш Google Calendar. Нужен OAuth Client ID (тип «Веб-приложение») из Google Cloud Console, адрес этого сайта добавьте в «Разрешённые источники JavaScript».
